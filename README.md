# 장소를 찾아드려요

카카오 지도 API로 장소를 검색하고, 결과를 지도 위에 마커로 보여 주는 프로젝트입니다.
**검색은 파이썬이, 지도 그리기는 브라우저가** 맡습니다.

## 할 수 있는 일

- 검색어(예: `성수동 카페`)로 장소를 찾아 지도에 마커로 표시
- 마커를 누르면 장소 이름과 주소 표시, 모든 마커가 한 화면에 들어오게 자동 조절
- 주소 ↔ 좌표 변환
- 목록 파일(`가게이름 | 주소`)의 가게가 실제로 있는지 카카오 검색으로 확인

## 파일 설명

| 파일 | 역할 |
| --- | --- |
| `app.py` | Streamlit 화면. 검색창·개수 슬라이더·지도·결과 표 |
| `make_map.py` | 장소 목록으로 지도 HTML을 만드는 `kakao_map()` / `kakao_map_html()`. 직접 실행하면 `map.html` 생성 |
| `place.py` | 키워드로 장소 검색 `search_place()` |
| `geo.py` | 주소 → 좌표, 좌표 → 주소 |
| `factcheck.py` | `1.txt`의 가게가 진짜 있는지 ✅ / 🟡 / ❌ 로 판정하고 실수율 계산 |

## 시작하기

### 1. 준비

```
conda activate camp312
pip install -r requirements.txt
```

### 2. 키 넣기

프로젝트 폴더에 `.env` 파일을 만들고 카카오 개발자 콘솔에서 받은 키를 넣습니다.
(키 이름은 `.env.example` 참고, `.env`는 깃에 올라가지 않습니다)

```
KAKAO_REST_API_KEY=...   # 장소 검색용 (파이썬에서만 사용)
KAKAO_JS_KEY=...         # 지도 그리기용 (브라우저로 전달됨)
```

두 키는 서로 다른 값입니다. REST 키는 HTML이나 화면에 절대 들어가지 않습니다.

### 3. 카카오 콘솔 설정

- **카카오맵 사용 설정**을 켭니다.
- JavaScript 키의 **JavaScript SDK 도메인**에 지금 열 주소를 포트까지 똑같이 등록합니다.
  - Streamlit: `http://localhost:8501`
  - `map.html`: `http://localhost:8001` (아래 서버 포트와 같게)

### 4-A. Streamlit 화면으로 쓰기

```
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 엽니다. `.env`를 고쳤다면 `Ctrl+C`로 끄고 다시 실행하세요.

### 4-B. map.html로 쓰기

```
python make_map.py                                      # 검색어를 입력하면 map.html 생성
python -m http.server 8001 --bind 127.0.0.1             # 이 폴더에서 서버 켜기
```

브라우저에서 `http://localhost:8001/map.html` 로 엽니다. 파일을 더블클릭해서 열면 지도가 뜨지 않습니다.
`--bind 127.0.0.1`은 빼지 마세요. 빼면 같은 와이파이의 다른 사람이 이 폴더의 파일(`.env` 포함)을 받아 갈 수 있습니다.

### 4-C. 가게 목록 확인하기

`1.txt`에 한 줄에 하나씩(`가게이름 | 주소`) 적고 실행합니다.

```
python factcheck.py
```

- ✅ 이름이 같은 곳이 있고 주소의 구·동(길)이 맞음
- 🟡 가게는 있지만 주소가 다름
- ❌ 찾지 못함

마지막에 개수와 실수율(🟡+❌ 비율)을 보여 줍니다.
번지수는 비교하지 않으므로, 구·길 이름만 맞고 번지가 다른 경우도 ✅가 될 수 있습니다.

## 지도가 회색일 때

1. 카카오맵 사용 설정이 켜져 있는지
2. 지금 주소(포트까지)가 JavaScript SDK 도메인에 등록돼 있는지
3. `file://`이 아니라 서버 주소(`http://localhost:...`)로 열었는지

## 주의

- REST 키는 `.env`에서만 읽고, 화면·HTML·깃에 넣지 않습니다.
- 지도 HTML(`map.html`)에는 JS 키가 들어가므로 깃에 올리지 않습니다(`.gitignore`).
- 좌표는 한국 범위(위도 33~39, 경도 124~132) 밖이면 잘못된 값으로 보고 버립니다.

## 사용한 API

- 카카오 로컬 API (키워드로 장소 검색, 주소↔좌표 변환)
- 카카오 지도 JavaScript SDK
